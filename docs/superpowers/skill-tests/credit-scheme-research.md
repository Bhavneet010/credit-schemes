# Credit Scheme Research Skill Test

## Baseline without the skill

Three realistic prompts were tested: add Punjab, refresh HP horticulture only, and
refresh PMFME for HP after a central guideline. Baseline reasoning recognized official
sources and focused research, but did not consistently emit a formal mode/scope,
out-of-scope hash guard, candidate/verified-none memory, reverse-index propagation, or
the required completion report.

## Guided acceptance

The same prompts pass when the response declares the exact mode and IDs before research,
uses the appropriate breadth for `add-state`, limits refreshes to declared dependencies,
applies claim/status evidence gates, preserves candidate memory and unchanged records,
and reports cutoff, sources, changes, QA, limitations, and outputs.

The guided pass correctly classified five variants (`add-state`, `refresh-sector`,
`refresh-scheme`, `audit-scope`, and `refresh-family`). Its remaining ambiguities were
closed with manifest-based defaults, a reverse-index-only dependency boundary, an index
integrity gate, a production-ready definition, and a one-retry/14-day failed-access rule.
